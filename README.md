# Biotechnology Student Portfolio

A desktop-first, single-page portfolio built with HTML, CSS, and vanilla JavaScript. It has no build step, framework, or paid API dependency.

## Preview in VS Code with Live Server

1. Open the `biotech-portfolio` folder in VS Code.
2. Install the **Live Server** extension by Ritwick Dey if it is not already installed.
3. Open `index.html` in the editor.
4. Click **Go Live** in the VS Code status bar, or right-click `index.html` and select **Open with Live Server**.
5. The site opens in your browser, usually at `http://127.0.0.1:5500/`.

Live Server is recommended because the resume check uses a local HTTP request. The layout itself can also be previewed by opening `index.html` directly, but the browser may block the resume check in `file://` mode.

This portfolio is designed for PC screens with a minimum layout width of 1024 CSS pixels. Phone and narrow tablet layouts and the mobile navigation have intentionally been removed; on smaller screens, the desktop layout may require horizontal scrolling.

## Publish a public link with GitHub Pages

The included `.github/workflows/deploy.yml` publishes the site whenever you push to the `main` branch.

1. On GitHub, create a **public** repository named `biotech-portfolio` under the account `ankitkumar9122`. Leave the options to add a README, `.gitignore`, or license unchecked so the repository starts empty.
2. In this folder, open a terminal and run:

   ```sh
   git init -b main
   git add index.html style.css script.js README.md .github/workflows/deploy.yml
   git commit -m "Publish biotechnology portfolio"
   git remote add origin https://github.com/ankitkumar9122/biotech-portfolio.git
   git push -u origin main
   ```

3. In the repository on GitHub, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
4. Open the repository's **Actions** tab and wait for **Deploy portfolio to GitHub Pages** to complete successfully.

The public site address will be `https://ankitkumar9122.github.io/biotech-portfolio/` once GitHub Pages finishes deploying. The address is reserved by this setup guide, but is not live until the repository is created and the workflow succeeds.

## Personalize the site

The site is personalized for Ankit Kumar and includes the supplied contact links and Lovely Professional University. Add an accurate degree or program and expected graduation year when ready; those details remain placeholders.

The project cards are clearly marked **Project idea** and describe possible learning exercises, not completed projects. Replace their titles, descriptions, tags, and GitHub destinations with work you have actually done before presenting them as your projects. The links currently lead to Ankit's GitHub profile.

## Add a resume

Place your PDF in this folder and name it `resume.pdf`. With the site running in Live Server, the contact section detects the PDF and reveals the download button. Keep the filename exactly `resume.pdf`, or update the corresponding path in `index.html` and `script.js` if you prefer another name.

## Accessibility and desktop behavior

- The page includes a skip link, visible keyboard focus styles, semantic landmarks, and reduced-motion support.
- The navigation links remain visible in the desktop header.
- The current year in the footer is generated by JavaScript.

No build command is required. Google Fonts are an optional enhancement; system font fallbacks are included for offline use.
